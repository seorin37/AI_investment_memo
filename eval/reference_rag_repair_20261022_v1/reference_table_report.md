# 새 공시 RAG 평가 기준표

## 결과

- 총 질문: 100개
- 보고서별 gold 항목: 116개
- 공식 원문 기반 직접 근거 확인: 94개
- 질문 전제가 평가 범위에 미공시: 2개
- 최신 공식 원문 미제공: 4개
- 사람 승인 상태: 100개 pending

## 파일 사용법

- `reference_annotations.jsonl`: 프로그램 평가용 원본. 질문, 필수 사실 그룹, 답 근거, 접수번호, 실제 섹션, 청크 ID, 단위·부호·계산·허용오차를 포함한다.
- `reference_review.csv`: 사람이 100개를 한 행씩 검토하는 표다. Excel에서 바로 열 수 있도록 UTF-8-SIG로 저장했다.
- `gold_change_log.csv`: 기존 보고서/섹션과 제안 보고서/실제 근거 섹션의 변경 근거다.
- `unresolved_items.csv`: 미공시 2개와 최신 원문 미제공 4개를 포함하며, extraction loss 항목도 추적한다.

## 평가 로직

각 `required_fact_groups`는 모두 충족해야 한다(AND). 한 그룹의 `alternatives_or`와 `valid_evidence_or`는 그중 하나면 된다(OR). 숫자 답은 공시 원단위 값의 정확 일치를 기본으로 하고, 명시된 계산 문항만 원단위 기준 반올림 오차 1을 허용한다. 비교 질문은 두 보고서에서 같은 정의와 같은 단위를 사용한다.

## 확정 전 예외

- SK-15: 2025 사업보고서 전체에서 미국의 대중국 반도체 수출규제/수출통제 공시를 확인할 수 없어 평가셋 제외 또는 질문 재작성 대상이다.
- SK-24: 2025 3분기 보고서에 CXL은 있으나 PIM은 없어 평가셋 제외 또는 CXL 단독 질문으로 재작성할 대상이다.
- KB-02, KB-11, KB-12, KB-22: 최신 정정본 원문이 제공될 때 직전 정정본과 차이를 재확인해야 한다.
