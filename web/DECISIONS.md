  - 금융업은 매출과 영업이익을 —로 보여 줘요.
- 고친 버그:
  - 체크리스트가 전역 1개였고 SK하이닉스에서만 보였어요. 이제 종목마다 따로 있어요.
  - 메모는 종목별로만 보여요.
  - 스튜디오가 종목을 바꿔도 같은 3종목 내용이었어요. 이제 고른 종목으로 결과를 만들어요.
  - 종목 고르기 화면 위쪽이 잘렸어요.
  - 메모 창의 AI 연결 토글을 오른쪽 끝으로 옮겼어요.
  - 날짜가 고정돼 있었어요. 이제 오늘 기준 거래일로 계산해요.
  - 네이버 표기를 통일했어요.
- 메모 AI 연결:
  - 메모 글에서 추적 항목을 찾아요. 실적, 배당, 자사주, 수주, 가격 조건 같은 것이에요.
  - 최근 7거래일 소식부터 매칭해요.
  - 새 소식 배지를 보여 줘요.
  - 타임라인 순서는 소식, 수정, AI 연결 시작, 첫 메모예요.
- 스튜디오: 진행이 끝나면 결과를 '만든 항목'에 저장해요.
  - 사용량은 오디오와 보고서 +8%, 실험실 +4%예요.
  - 서버 응답이 실패하면 실패 화면이 나오고 사용량은 그대로예요.
- 설정:
  - 프로필 이름, 직업, 사진을 바꿀 수 있어요.
  - 알림 스위치가 알림함과 연동돼요.
  - 데이터 내보내기(JSON)가 있어요.
  - 전체 삭제는 종목까지 지우고 계정은 남겨요.
  - 탈퇴하면 계정이 삭제돼요.
  - 정보 화면에 오픈소스 라이선스, 도움말에 FAQ를 넣었어요.
- 점검:
  - `e2e/full-flow.cjs` 63항목이 모두 통과했어요.
  - tsc, oxlint(오류 0), vite build 모두 통과했어요.
  - 콘솔 오류는 없어요.

## 11.18 (2) — 팀 피드백 5가지 반영

- **다크 모드 메모지**
  - 밝은 파스텔이 그대로 보여 눈이 부셨어요. 이제 같은 색 계열의 어둡고 차분한 종이에 밝은 글자로 보여요.
  - 색은 `data.ts` `PAPER[].dk`에 있어요. 화면 반전 필터를 거친 뒤 실제로 보이는 색 기준으로 맞췄어요.
  - 메모 창, 색 고르기, 목록, 홈 위젯의 메모 색도 같은 색이에요. CSS 변수 `--pp-*`·`--pk-*`(`theme.css`)를 써요.
  - 오른쪽 아래 접힌 귀퉁이에 흰 선이 보였어요. 원인은 귀퉁이를 배경색 삼각형으로 덮던 방식이었어요.
  - 이제 종이를 잘라서 귀퉁이를 만들어요(`clip-path`). 잘린 자리로 실제 화면 배경이 보여서, 다크 모드에서도 흰 선 없이 배경과 같은 검정이에요. 접힌 부분은 `PAPER[].dk.accent` 색이에요.
  - 앱과 맞출 다크 모드 색표(화면에 실제로 보이는 값):

    | 색 | 종이 | 접힌 부분·테이프 |
    |---|---|---|
    | 노랑 | `#5F5129` | `#B39338` |
    | 초록 | `#29523F` | `#3F9A66` |
    | 파랑 | `#2B4268` | `#5380DA` |
    | 보라 | `#44386E` | `#8C70E6` |
    | 분홍 | `#5D2D56` | `#C25AAF` |

    화면 배경 `#18191B`. 글자: 제목 `#F2F2F4`, 본문 흰색 80%, 작성일 흰색 62%. AI 연결 버튼 원: 켜짐 흰색 22%, 꺼짐 흰색 8%.
  - 팝업 뒤를 덮는 막이 다크 모드에서 오히려 밝게 덮였어요. 이제 어둡게 덮여요.
- **종목 이름은 늘 가로로**
  - 최신 업데이트의 종목 칩은 글자를 꺾지 않아요. 자리가 모자라면 칩이 다음 줄로 넘어가요. 검은 선택 표시도 줄을 따라가요.
  - 홈 '업데이트' 위젯에서 이름과 보유/관심 배지는 한 줄로 붙어 있어요. 오른쪽 상태 글자("연결된 소식 없음")는 자리가 모자라면 다음 줄 오른쪽으로 내려가요.
  - 스튜디오 종목 목록도 이름이 길면 말줄임(…)으로 한 줄에 둬요.
- **그래프 선이 끊기던 버그**
  - 원인은 선 그리기 애니메이션이었어요. 점선 길이를 400으로 고정했는데, 화면에서 400px보다 긴 선(1년 그래프, 넓은 화면)은 중간이 비었어요.
  - 이제 왼쪽에서 오른쪽으로 걷어내듯 보여 줘요(`motion.css .m-line`). 그래프 길이와 상관없이 끝까지 이어져요.
- **메모·체크리스트 위치 바꾸기**
  - 보드에서 카드를 끌어서 옮겨요. 마우스는 누른 채 움직이면 되고, 터치는 0.35초 꾹 누르면 집혀요.
  - 끄는 동안 놓일 자리에 점선 칸이 생기고, 다른 카드는 미끄러지듯 비켜요. Esc를 누르면 취소돼요.
  - 화면 끝으로 가면 자동으로 스크롤돼요. 빈 칸으로도 옮길 수 있어요.
  - 배치는 종목마다 저장돼요(`UserState.boards`). 새로고침이나 재로그인 뒤에도 남아요.
  - 새 메모와 새 체크리스트는 원래 칸 맨 위에 생겨요.
  - 테이프를 붙이면 그 칸 맨 위로 올라가요. 그 뒤에는 자유롭게 옮길 수 있어요. 문구도 '맨 위에 고정'에서 '칸 맨 위로'로 바꿨어요.
  - '전체' 보기이고 격자 보기일 때만 옮길 수 있어요. 필터를 켰거나 선택 중일 때는 옮기지 않아요.
  - 처음에는 보드 머리에 "꾹 눌러 끌면 위치를 바꿀 수 있어요" 안내가 보여요. 한 번 옮기면 사라져요.
- **점검**
  - `e2e/full-flow.cjs`에 N구역 21항목을 더했어요. 다크 메모 밝기, 귀퉁이, 이름 꺾임, 칩 높이, 그래프 선, 마우스·터치 끌기, Esc 취소, 저장 유지를 확인해요.
  - 전체 84항목 통과, tsc·oxlint(오류 0)·vite build 통과, 콘솔 오류 없음.

## 11.18 (3) — 끌어서 옮길 때 다른 카드는 옆으로

- 팀 피드백: 카드를 옮길 때 그 자리 카드가 아래로 내려가는 게 어색하다. 다른 앱처럼 옆으로 밀려야 한다.
- 보드를 3칸 세로 쌓기(칸마다 따로)에서 **3칸 격자 + 순서 하나**(왼쪽→오른쪽, 위→아래)로 바꿨어요. 휴대폰 홈 화면 위젯과 같은 방식이에요.
  - 카드를 어떤 자리에 놓으면 그 자리부터 뒤 카드가 한 칸씩 옆으로 밀려요. 줄 끝 카드는 다음 줄 첫 칸으로 넘어가요.
  - 저장 모양: `UserState.boards[code]` = `string[]`. 오전에 3칸 배치로 저장된 것은 왼쪽→오른쪽 순서로 바꿔 읽어요.
  - 새 메모·새 체크리스트는 맨 앞(왼쪽 위)에 생겨요. 테이프를 붙이면 맨 앞으로 올라가요.
- 격자 칸 크기를 맞추려고 체크리스트 카드도 메모와 같은 높이(200)로 고정했어요. 항목이 4개 이상이면 2개만 보이고 "외 N개 더 있어요"가 나와요. 누르면 전체가 열려요.
- 점검: e2e 85항목 통과 (옆으로 밀리는지 확인하는 항목 추가). 마우스·터치 모두 확인했어요.

## 11.18 (4) — 웹 UI 추출서 기준 맞추기

- **데이터 필드 이름 snake_case**: `src/api/types.ts`(API 데이터)와 `src/data.ts`(화면용 데이터), 가상 데이터(`src/api/mock/`) 필드를 모두 snake_case로 바꿨어요.

- **주가 기준 표기**: "MM.DD 종가 기준"으로 통일 (종목 머리·기업 정보·홈 시장 카드 1일·지수 자세히·내 종목).
