# AI 주간보고서 화면 디자인 정리 결과

## 바꾼 점

### 웹 자세히 보기

- 860px `FixedFrame`과 종목 섹션 카드 형식은 유지했다.
- 종목별 읽는 순서를 `핵심 숫자 → 최근 분기 실적 → 이번 주 흐름 → 이번 주 이슈 정리 → 이번 주 소식 → 내 메모 → 앞으로 지켜볼 것`으로 통일했다.
- 주간 등락·최고·최저·거래량과 PER·PBR·시가총액·52주 위치를 하나의 숫자 블록으로 묶었다.
- PER·PBR은 해석 문구 없이 숫자만 표시한다.
- 최근 분기 실적은 별도 리포트 블록으로 묶고 순이익도 함께 표시한다.
- 국내 증시 영역에 지수 값, 등락률, 시황 본문, 날짜별 흐름의 위계를 만들었다.
- 소식 목록에 차트 번호를 함께 표시하고 긴 제목을 한 줄로 자르지 않게 했다.
- 메모 제목·메타·본문과 실제 `linked_count`를 보여 주고, 메모가 없으면 짧은 빈 상태와 `메모 쓰기`를 표시한다.
- `앞으로 지켜볼 것`에서 기존에 빠져 있던 `why`를 근거 줄로 표시한다.

### 웹 스튜디오 열 요약·만들기 창

- 요약 화면의 실제 거래일 수 표시와 5일 미만 데이터 처리를 유지했다.
- 만들기 창에 `N개 선택` 상태를 추가하고 국내 증시 옵션 명칭을 `국내 증시 주간 요약`으로 통일했다.

### 앱 보고서·만들기 시트

- 웹과 같은 정보 순서로 맞췄다.
- 숫자는 모바일 2열 카드로 묶고 밸류와 분기 실적이 기존 숫자 표의 일부처럼 보이게 정리했다.
- 이슈 정리는 왼쪽 강조선과 옅은 배경을 사용해 소식 목록과 구분했다.
- 소식이 없는 종목, 메모가 없는 종목에도 작은 빈 상태를 표시한다.
- 만들기 시트의 종목명과 설명을 한 묶음으로 바꿔 좁은 화면의 가로 밀도를 낮추고 선택 개수를 표시했다.

### 공용 조각

- `stripRefs`를 시황·종목 흐름 본문에 공통 사용했다.
- PER·PBR의 `배` 접미사를 제거했다.
- 분기 실적 한 줄에 순이익을 추가했다.
- 거래일이 하루뿐이어도 `Spark`, `SparkWide`, 웹 미니 차트의 좌표 계산이 깨지지 않게 했다.
- `WeekChart`와 `DetailChart`의 5일 미만 처리 방식은 유지했다.
