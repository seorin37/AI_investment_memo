## 5. "140만원 넘으면 살까?"는 답만, 답 아래 [알림 받기] 제안

- 대신 코드가 읽은 조건(140만원·이상)을 질문 항목의 가격 칸·핵심어(`alert:price_above`)에 남긴다 (`app/board/tracking.ask_item`, 마이그레이션 없음). 추적·가격 카드는 생기지 않는다.
- 답 카드 아래에 코드가 만든 제안 **"🔔 140만원 넘으면 알려드릴까요? [알림 받기]"** (`price_brief.alert_suggestion` → `details.suggest_memo` → `GET /updates` `suggest_memo`).
- [알림 받기] → 이 종목 **새 메모 창**이 "140만원 넘으면 알려줘"로 채워지고 AI 연결이 켜진 채 열린다 (웹 `stocks/[code]` 메모 창, 앱 `/memo/evidence` → `/memo/new`). 사용자가 저장하면 평소처럼 가격 알림이 잡힌다 (추적 상한·크레딧 검사 그대로). 밑으로는 "130만원 밑으로 가면 알려줘".
