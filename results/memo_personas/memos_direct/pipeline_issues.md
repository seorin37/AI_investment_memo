# 판정 파이프라인 문제 목록 (평가 메모 1,000개로 확인)

`backend/pipelines/tracking`의 문장 분리(segment.py)와 규칙 판정(judge.py)을 평가 메모의 라벨과 대조한 결과입니다.
라벨은 메모 작성 의도 기준이고, 규칙 판정은 LLM 단계 전에 확정되는 것만 비교했습니다.

## 요약 (사람이 정리)

1. **문장 분리(segment.py)가 연결 표현에서 자른다 (70건)**
   - `-니` 계열: "기사 보니 / …", "들고 있으니 / …", "팔렸다니 / …", "받쳐주니 / …", "늘 테니 / …"
   - `-자`로 끝나는 명사: "판매자 / 수수료…", "이용자 / 수…", "시설투자 / 공시…"
   - "~것 같아요"를 "것 / 같아요"로, "먹다가"를 줄인 "먹다 / …"를 끝으로 봄
   - 반대로 덜 자르는 경우는 0건
2. **규칙 판정 ④-2(짧은 문장 = 범위 밖 B5)가 앞 문장을 받는 짧은 문장을 버린다 (7건)**
   - "이건 좀 실망", "그래도 기대됨", "120만이면 더 삼", "거기서 몇 주 더", "마이크론보다 앞서는지"
   - 종목명이 없는 짧은 후속 문장이라 B5가 되지만, 실제로는 앞 문장 대상에 대한 감정·조건·비교(C1·C2·C3)다
3. **`configs/tracking_lexicon.yaml` NAVER 별명에 "넵"이 없다**
   - "넵 20일선 넘는지..."가 종목을 못 찾아 B5로 판정됨 (페르소나 100명 중 14명이 "넵"을 별명으로 씀)
4. **"거래량 터지" 표현을 지원 안 하는 가격 조건으로 본다 (3건)**
   - 조건이 아닌 관찰·가설 문장("거래량 이렇게 터지는 거 보면…")과 절대 가격이 같이 있는 문장("거래량 또 터지면서 22만 깨지면")까지 확인 필요가 됨
